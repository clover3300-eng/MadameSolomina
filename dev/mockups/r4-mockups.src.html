Раунд 4 · «Обзор» и страница портфеля
«Лист»

Вся страница — один лист бумаги, на котором всё набрано, а не разложено по коробкам. Крупное тонкое число, волосяная кривая, оглавление портфелей с точками-лидерами, полоса «из чего собрано», две тихие колонки — и ни одной плашки, пока она правда не нужна. Обновление после первого просмотра: на лист добавлено распределение по классам — тонкая полоса с насечкой цели прямо под оглавлением портфелей; и дорисован полный набор состояний обеих страниц.

первоеЛист вместо коробок

Наверху страницы нет карточек. Есть один лист: воздух 52 px по краям, волоски вместо границ. Ритм задаёт типографика, а не сетка виджетов.

второеТише — значит дороже

Цвет только на дельтах, и приглушённый: терракота вместо алого, тёмно-зелёный вместо салатового. Полоса классов — ступени серого, а не радуга.

третьеКнопка — только по делу

Пока всё в порядке, страница ничего не просит. Есть проблема — появляется одна строка на полях с текстовой ссылкой.

четвёртоеГлубина по требованию

Подробности живут внутри строк и разворачиваются на месте. Ничего не открывается поверх, ничего не уводит со страницы.
