# Архитектура Terminal Madame Solomi'na

Статический SPA-терминал (расчёт портфеля ОФЗ+акции, ребаланс, рынок, бэктест)
без сборщика и фреймворков. Хостинг — Cloudflare Workers Static Assets.

## Структура репозитория

```
├── public/              ← весь сайт (деплоится как статика)
│   ├── index.html       ← единственная страница: разметка ВСЕХ вкладок + порядок подключений
│   ├── js/              ← по файлу на фичу (см. таблицу ниже)
│   ├── css/             ← по файлу на фичу; порядок каскада несущий
│   └── img/
├── wrangler.jsonc       ← конфиг Cloudflare (assets → public/)
├── package.json         ← только для деплоя, рантайм-зависимостей нет
└── ARCHITECTURE.md      ← этот файл
```

## Ключевые правила (нарушение = баги)

1. **Нет ES-модулей.** Все скрипты — классические `<script defer>`, общая
   глобальная область видимости. Функция из файла A доступна в файле B
   в рантайме без импортов.
2. **Порядок `<script>`-тегов в index.html — несущий.** `defer`-скрипты
   исполняются строго по порядку. Код верхнего уровня (`var _orig = fn`,
   оборачивание `switchTab`) видит только то, что загружено ВЫШЕ.
   Вызовы в рантаиме (клики, DOMContentLoaded) видят всё.
3. **Идиома «патч поверх оригинала»:** рабочая версия функции — часто
   ПОЗДНЕЕ переопределение (`var _orig = fn; fn = function(){...}`).
   Править нужно последнюю редефиницию, а не первую по файлу.
4. **Оборачивание `switchTab`** — штатный способ модуля реагировать на вход
   во «свою» вкладку (так делают stock-terminal.js, bond-terminal.js,
   portfolios.js и др.). Оборачивай `window.switchTab`, вызывая предыдущий.
5. **Кэш-бастинг:** при правке js/css поднимай `?v=N` в index.html.
6. **CSS:** порядок файлов — контракт. `desktop-zoom.css` всегда ПОСЛЕДНИЙ
   (глобальный зум 85% на десктопе; компенсации только через `--real-vh` в px,
   никогда через vh). Поздние файлы намеренно перебивают ранние
   (например, backtest.css перебивает site-layout.css селекторами из 2 id).

## Как добавить новую фичу/вкладку

1. Создай `public/js/имя-фичи.js` и `public/css/имя-фичи.css` со своим
   префиксом классов (примеры: `.stk-`, `.bnd-`, `.mi5-`, `.rb5-`, `.pft-`).
2. Подключи js после webapp-tabs.js (и после файлов, чьи функции нужны
   на верхнем уровне), но до route-hash.js; css — до desktop-zoom.css.
3. Реагируй на открытие вкладки обёрткой `window.switchTab`.
4. Разметку панели добавь в index.html (`#panel-имя`) или собирай в рантайме.
5. Новые контролы в существующей карточке — переиспользуй её компоненты
   (например, `.mh-seg/.mh-seg-btn`), не изобретай свои.

## Данные и хранилище

- **MOEX ISS API** (бесплатный, без ключа) — котировки, история, индексы.
- **Google Sheets CSV** (опубликованные) — таблицы акций/облигаций терминалов.
- **Google Apps Script** — API пользователей (core.js).
- **localStorage:** `msolominа_state` (app-state.js), `portfolios_v1`,
  `dash_portfolio_v1`, `stk_fav_v1`, `bnd_fav_v1` (ISIN).

## Известные ограничения / план на будущее

- **portfolios.js (~3900 строк)** — один IIFE с общим closure-состоянием
  (модель, котировки, хелперы). Внутри секции: модель/persist, графики,
  карточки, редактор, карточка ребалансировки R5, история сделок, избранное.
  Дальнейшая декомпозиция требует общего неймспейса (`window.PF`) и тестов —
  резать без них не стоит.
- **index.html (~2100 строк)** — вся разметка вкладок в одном файле; без
  сборщика это осознанный компромисс.
- Фиксированные оверлеи монтируются в `<body>` (не внутрь панелей):
  `transform` анимаций вкладок ломает `position: fixed` у потомков.
