## Карточка портфеля, раунд 4: одна пилюля, тихий график, три размера

Четыре замечания к «Табло»: две дельты под суммой вместо одной, чип «⇄ сравнить»
поверх кривой, трёхстрочный столбик будущей выплаты и просьба про три размера
**S / M / L** с условием «имя портфеля видно всегда». Диагноз один на все четыре:
верхний этаж собирался по частям, и на 350px высоты стоят **четыре независимых
контрола**. Поэтому чинятся вместе — пилюля забирает период, и сегменты уходят из
шапки; сравнение и выплата уходят с полотна в одну тихую строку под графиком;
после этого этажи отделимы и S / M / L — просто вопрос, где обрезать.

Экраны: **00** три размера рядом (S ≈ 315px до KPI · M ≈ 495 с KPI · L ≈ 1010 всё
до «Ребаланса» с пятью позициями) · **01** пилюля, три решения (**П1** меню с
цифрами всех периодов — рекомендую · **П2** циклер · **П3** сегменты остаются) ·
**02** график, три решения (**Г1** подпись под кривой — рекомендую · **Г2** всё в
ховер · **Г3** однострочная метка) · **03** шапка на четырёх тяжёлых случаях,
«сейчас» против «предложения», с замерами · **04** чем переключается размер
(авто по высоте блока + оверрайд в настройках виджета; почему не `@container` по
высоте) · **05** тёмная тема, 380px, краевые · **06** карта «элемент → где в коде».

Замеры экрана 03 сняты с собранной страницы, не на глаз: в худшем случае шапка
**на 128px шире карточки**, а `overflow:hidden` у `.pf-card`/`.dash2-card` нет —

Пересборка после правки исходника — имя набора аргументом:

```sh
node dev/mockups/build-mockups.js            # trading (по умолчанию)
node dev/mockups/build-mockups.js pf-card
```

Сборщик кладёт рядом ещё `*-mockups-artifact.html` — ту же страницу без
обёртки `<html>/<head>/<body>` для публикации. Он в `.gitignore`: генерируется
из исходника и в истории не нужен.

**Почему статика, а не живой скрипт.** Просмотрщики часто показывают HTML
снимком, не выполняя `<script>` — тогда все экраны оказываются пустыми `<div>`.
Поэтому итоговая страница не содержит ни одного скрипта.

**Ловушка при правке.** Пины-выноски ставятся по координатам, снятым JS-замером
с собранной страницы (getBoundingClientRect цели относительно `.scr`), — не на
глаз. Поменял разметку экрана — сними координаты заново.

Решения, которые стоят за макетами, — в памяти проекта: `trading-scene-module`,
`trading3-mockups`.
