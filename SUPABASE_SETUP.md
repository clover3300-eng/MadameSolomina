# Подключение Supabase: аккаунты, синхронизация, админка

Аккаунт на supabase.com уже есть — дальше 10 минут по шагам.
Пока шаги не выполнены, сайт работает как раньше (локальный демо-режим),
ничего не ломается.

## 1. Создать проект

1. [supabase.com/dashboard](https://supabase.com/dashboard) → **New project**.
2. Name — например `madame-solomina`, Region — **Frankfurt (eu-central-1)** (ближе к пользователям из России), Database password — сгенерировать и сохранить (для сайта он не нужен).
3. Подождать ~2 минуты, пока проект поднимется.

## 2. Выполнить SQL-схему

1. В левом меню проекта: **SQL Editor** → **New query**.
2. Скопировать содержимое файла [`supabase/schema.sql`](supabase/schema.sql) целиком, вставить, нажать **Run**.
3. Должно закончиться без ошибок («Success. No rows returned»). Повторный запуск безопасен.

Что создаётся: таблицы `profiles` (роль/бан/активность), `user_data`
(синхронизация портфелей и настроек), `app_events` (журнал), RLS-политики
(каждый видит только своё, админ — всё) и триггеры (профиль при регистрации,
защита от снятия последнего админа).

## 3. Вставить ключи в сайт

1. **Project Settings → API** (шестерёнка внизу слева).
2. Скопировать **Project URL** и **anon public** ключ.
3. Открыть [`public/js/supabase-config.js`](public/js/supabase-config.js) и заполнить:

```js
window.SUPABASE_URL = 'https://xxxxxxxxxxxx.supabase.co';
window.SUPABASE_ANON_KEY = 'eyJhbGciOi…';
```

`anon`-ключ публичный, его можно коммитить: данные защищает RLS.
Секретный `service_role` ключ в сайт вставлять **нельзя никогда**.

## 4. Настроить авторизацию

**Authentication → URL Configuration:**
- **Site URL** — адрес сайта, например `https://madamesolomina.ru`
  (на него ведут ссылки из писем подтверждения/сброса пароля).
- В **Redirect URLs** добавить `http://localhost:8787/**` — чтобы вход работал и при локальной разработке (`npx wrangler dev`).

**Authentication → Sign In / Up → Email:**
- Провайдер **Email** включён по умолчанию — оставить.
- **Confirm email** — на ваш вкус:
  - включено (по умолчанию): пользователь должен подтвердить почту письмом. Встроенная почта Supabase шлёт **до ~4 писем в час** — для продакшена позже стоит подключить свой SMTP (Authentication → Emails → SMTP Settings);
  - выключено: регистрация мгновенная, без писем — удобно для старта и тестов.

Письма по умолчанию на английском — русские шаблоны правятся в
**Authentication → Emails → Templates**.

## 5. Назначить себя администратором

1. Зарегистрироваться на сайте (форма на Главной) — обычным пользователем.
2. В **SQL Editor** выполнить (подставив свой email):

```sql
update public.profiles set role = 'admin' where email = 'clover3300@gmail.com';
```

3. Обновить сайт — в сайдбаре появится пункт **«Админка»** (и кнопка в личном кабинете). Дальше роли раздаются из самой админки.

## Что уже умеет сайт после подключения

- **Регистрация и вход** на Главной — настоящие (Supabase Auth), с русскими сообщениями об ошибках, подтверждением почты и «Забыли пароль?» (письмо → форма «Новый пароль»).
- **Личный кабинет** — имя/email редактируются и хранятся в облаке (смена email — через письмо-подтверждение), пилюля показывает «облако» вместо «локально».
- **Синхронизация**: портфели, история сделок, избранные акции/облигации, параметры расчёта и настройки автоматически уезжают в облако и приходят на любое устройство после входа. При выходе личные данные с устройства убираются (в облаке остаются).
- **Админка** (`/admin`): обзор с KPI и графиком регистраций за 14 дней, таблица пользователей с поиском (роль, бан, онлайн-статус, данные), карточка пользователя (портфели и все сохранённые данные, события, очистка данных), журнал событий с фильтрами. Опасные действия — с подтверждением «Точно?»; снять последнего админа не даст сама база.

## Ограничения (сознательные)

- **Полное удаление аккаунта** — только из Supabase Dashboard → Authentication → Users (требует секретного ключа, который в браузер не кладут). Админка вместо этого умеет «Заблокировать» и «Очистить данные».
- **Вход через Telegram** — остаётся демо-заделом, к Supabase не подключён (нужен бот и серверная проверка подписи — отдельная задача).
- Бесплатный тариф Supabase: 500 МБ базы, 50 000 активных пользователей в месяц — для старта с запасом.
