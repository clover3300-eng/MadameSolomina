Портфели · Обзор · виджет «Новости по позициям»

«Новости по позициям» для нескольких портфелей: фильтр, лента, принадлежность

Сейчас виджет собирает бумаги всех портфелей в один список по размеру позиции, а принадлежность показывает только точками 7px — при нескольких портфелях не видно ни «чья» это бумага, ни что случилось сегодня. Редизайн отвечает на три вопроса: что нового (лента по свежести с группами дней), по какому портфелю (пилюли-фильтры портфелей с именем и цветом) и насколько это важно (дневное изменение у тикера, вес позиции на ховере).

Что меняется против текущего вида (назвать до утверждения): 1) чипы-тикеры убраны — они дублировали сам список; фильтр теперь по портфелям, «+» для внешних тикеров остаётся; 2) сортировка по умолчанию — «Свежесть» с группами Сегодня/Вчера/Ранее (тумблер «Вес» возвращает текущий порядок); 3) дневное изменение тикера показано — оно уже собирается в pfdNewsList, но не выводится; 4) принадлежность — точка + имя портфеля (до двух, дальше «+1»), а не безымянные точки; 5) строки без рамок-карточек — волосяные разделители в минимал-языке виджетов; 6) ховер-раскрытие заголовка сохранено и дополнено строкой «позиция»: сумма и вес в каждом портфеле.

ЭКРАН 0

Как сейчас

для сравнения

Чипы-тикеры с точками, строки-карточки по размеру позиции. Принадлежность нечитаема (точки без имён), свежее тонет внизу, изменение цены не показано, чипы съедают ярус и дублируют список.

ЭКРАН 1

Вариант А — лента по свежести с фильтром портфелей

основной вариант

Пилюли портфелей (цвет + имя) вместо чипов-тикеров, тумблер «Свежесть/Вес» как в «Избранном», группы Сегодня/Вчера/Ранее, у тикера — дневное изменение, справа — именованная принадлежность. Бумаги без новостей и внешние тикеры — вниз, отдельными группами.

1Пилюля портфеля: точка фирменного цвета + имя. Активная — чернильная заливка, как у контролов «Избранного». Повторный клик — назад к «Все».
2Тумблер «Свежесть/Вес» — тот же контрол, что сортировка «Избранного» (.fv-sort). «Вес» возвращает текущий порядок по размеру позиции, группы дней исчезают.
3Группы Сегодня/Вчера/Ранее — моно-каптал с волоском. Пока Apps Script не ответил по тикеру, строка ждёт в нижней группе «Загружается».
4Дневное изменение под тикером уже собирается в pfdNewsList (quotes[tk].chgPct) — сейчас просто не рендерится. Клик по тикеру — карточка компании, как сейчас.
5Принадлежность: до двух портфелей именами, дальше «+1» (полный список — на ховере). Внешний тикер — пунктирная метка «внеш.».
6Заголовок новости — одна строка с обрезкой; полный текст раскрывается ховером поповером (экран 2), клик открывает Smart-Lab.
ЭКРАН 2

Наведение: заголовок целиком + позиция в портфелях

ховер

Курсор на новости SBER: поповер поверх соседних строк (контент не сдвигается) — полный заголовок, мета и новая строка «Позиция»: сумма по бумаге и вес в каждом портфеле. Это ответ на «насколько эта новость меня касается» — главный вопрос при нескольких портфелях.

ЭКРАН 3

Вариант Б — группировка по портфелям

альтернатива

Вместо фильтра — постоянные секции: заголовок-портфель (цвет + имя + счёт бумаг), внутри строки по весу позиции, справа — доля бумаги в ЭТОМ портфеле. Бумага в двух портфелях повторяется в обеих секциях (новость из кэша, второй раз не грузится). Выбрать против экрана 1 — или сделать третьим положением тумблера: «Свежесть / Вес / По портфелям».

ЭКРАН 4

Тёмная тема

Вариант А на тёмном: волоски светлеют, активные пилюли остаются чернильными (светлая заливка на тёмном), Smart-Lab-пилюля — янтарная светлая, точки портфелей не меняются.

ЭКРАН 5

Узкая колонка конструктора

адаптация

На ширине ≤ ~380px имена портфелей сворачиваются в точки у тикера, заголовок новости получает две строки, пилюли скроллятся горизонтально. Правило «контент подстраивается под размер виджета» соблюдено: ни строка, ни пилюля не клипуются.
